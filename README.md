# Rajawat Farm House Website

## Files
- `index.html` — website homepage
- `images/` — the three real farm photographs supplied for this update

## Run locally
Open `index.html` in Chrome or Edge. Keep the `images` folder beside it; do not move or rename the image files.

## Google Maps
The map panel and the location button point to the exact Google Maps place shared by the owner (short link: https://maps.app.goo.gl/qb2NZATScvRdpYP49).

## Publish free with Netlify (easy option)
1. Extract this ZIP file.
2. Open Netlify Drop: https://app.netlify.com/drop
3. Sign in or create an account (ask a parent/guardian to help with account setup if needed).
4. Drag the complete `Rajawat_Farm_House_Website` folder onto the page — not just `index.html`.
5. Netlify will provide a public website link. Open it on your phone and check the photos, map and contact buttons.

## Alternative: GitHub Pages
1. Sign in to GitHub and create a new public repository.
2. Upload `index.html` and the complete `images` folder.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to show the published URL.

## Before publishing
- Check the phone number, email, address, crop information and any prices shown on the website.
- The contact form opens WhatsApp or the visitor's email app; it does not silently store submissions in a database.
- This is a static website. The map uses Google Maps' public embed/search URL and does not require putting an API key in the HTML.
